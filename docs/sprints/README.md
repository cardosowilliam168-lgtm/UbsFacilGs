# Sprints

Registros das cerimônias do Scrum. Preencher durante o trabalho, não depois.

- `TEMPLATE-daily.md`: copiar para `daily-AAAA-MM-DD.md` (uma por dia útil).
- `TEMPLATE-retrospectiva.md`: copiar para `retrospectiva-sprint-N.md` após a entrega.

Cerimônias da Sprint da GS: Planning no 1º encontro, Daily assíncrona no grupo, Review no 2º encontro e Retrospectiva após a entrega.
